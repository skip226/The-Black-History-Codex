# The Black History Codex

A searchable, mobile-friendly digital archive connecting Black history across eras, continents, people, movements, and ideas.

## MVP foundation

- Editorial homepage and mission
- Searchable historical collection
- Era-based filtering
- Interactive timeline
- Responsive, accessible design

## Development

The first MVP is built with Next.js, React, TypeScript, and CSS. Source development is taking place on the `develop/mvp-foundation` branch.
